# MSMS 制造业安全管理系统 · 仿制版（去千问化 + GitHub Gist 云同步）

制造业生产安全管理系统（63 模块）的**纯前端仿制版**：数据存本地 IndexedDB，云同步走 GitHub Gist，**不依赖千问办公 / Supabase 等任何商业 BaaS**。

## 快速开始

直接用浏览器打开 `index.html` 即可（双击或拖入浏览器），无需任何服务、构建或安装。

- 已内置示范工厂种子数据（苏州智造科技：组织/用户/隐患/风险/作业票/考试等）
- 首次打开自动初始化本地数据库

## 功能覆盖

- **63 模块全量骨架**：13 大类，P0 全流程可用（26 个），P1/P2 以概览/占位呈现
- **核心业务流**：
  - 双重预防：风险分级管控（LEC 四色分级）+ 隐患排查治理（全闭环状态机）
  - 特殊作业票（W1）：措施模板生成 → 逐条确认 → 气体检测 → 四方签名 → 开工前置校验
  - 在线考试（H2）：随机抽题 → 服务端判分 → 自动及格判定
  - 点检异常自动转隐患（E2→D2）、事故四不放过结案（I1）、CAPA 自动生成工单（I5）
  - 统一工单引擎（P8）、审计日志（P5）、消息中心（P6）
- **驾驶舱 / 报表**：安全态势一屏总览、隐患台账 CSV 导出

## GitHub Gist 云同步（手动备份/恢复）

顶栏两个按钮：

1. **「备份到云端」**：首次点击会提示输入 GitHub Personal Access Token（需勾选 `gist` 权限）。首次备份会自动创建一个**私有 Gist**，之后自动记住 Gist ID，再次点击即为增量覆盖（Gist 天然保留版本历史）。
2. **「从云端恢复」**：从 Gist 拉取数据快照覆盖本地（恢复前有确认提示）。

> 数据快照存为单个 `msms-data.json` 文件，包含全部 40+ 张表的数据。

## 注意事项

- **Token 安全**：GitHub Token 明文存在浏览器 localStorage，仅建议在可信设备使用；泄露后可随时在 GitHub 撤销该 Token。
- **单机优先**：数据本地为主，云端为快照备份；多人同时编辑同一 Gist 存在 last-write-wins 覆盖风险（MVP 单数据员场景可接受）。
- **数据量**：Gist 单文件上限 10MB，制造业台账规模远够用；超限可扩展为按表拆分多文件。

## 与原版的关系

- 仿制自千问办公托管版 `msms-cloud-workstation`（Node.js + Supabase）
- 数据层由 `server.js` 的 Supabase REST 平移到前端 `datastore.js`（IndexedDB），业务规则（SCHEMA 校验、状态机、编号、风险计算、特殊业务流）完全保留
- 详细反推分析见 `../MSMS反推分析与仿制方案.md`

## 2026-08-19 迭代记录（审核 + 修复 + 增强）

### 审核发现并修复的缺陷

| # | 问题 | 严重度 | 修复 |
|---|---|---|---|
| 1 | 「运行定时任务」按钮必现栈溢出：`index.html` 与 `datastore.js` 同名全局函数 `runJobs` 互相覆盖，route→runJobs→api→route 无限递归 | P0 | UI 包装改名 `runJobsUI`（按钮 onclick 同步） |
| 2 | 检查计划周期被忽略：`check_plan.plan_type` 存在但 `next_due_date` 一律 +1 天，周/月计划变每日 | P1 | 按 DAILY/WEEKLY/MONTHLY（大小写兼容）推进 |
| 3 | W1 开工缺少「同区域冲突作业检测」（动火/盲板/动土/临时用电互斥，PRD W1-BR01②） | P1 | 补回 CONFLICT_PAIRS 校验 |
| 4 | W2 承包商 admit 返回硬编码 `admitted:3` 假数据，缺评估分拦截 | P1 | 补 evaluation_score<3 拦截，返回真实结果（ok/activated） |
| 5 | 防火巡查转隐患 `source` 用中文「巡查」，与字典（PATROL）及点检（INSPECTION）不一致 | P2 | 统一 `PATROL`，防重复查询兼容旧中文数据 |

### 新增能力

- **台账编辑/删除**：全部 CRUD 模块表格行新增「编辑」「删除」操作（编辑回填表单走 PATCH 全字段合并，不触发状态机；删除走新增 DELETE 路由，含 RBAC 校验与审计日志；作业票删除级联清理子表）

- **运行结果明细**：「运行定时任务」弹窗展示全部 8 类任务摘要
